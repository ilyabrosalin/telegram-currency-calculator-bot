# Currency Calculator Bot

Telegram-бот на C#, который считает арифметические выражения и конвертирует валюты.

## Возможности

- [ ] Вычисление арифметических выражений (`5 + 3 * (2 - 1)`)
- [ ] Конвертация валют по актуальному курсу (`100 usd to rub`)
- [ ] История последних вычислений (`/history`)
- [ ] Очистка истории (`/clear`)

## Архитектура

```
CurrencyBot/
├── Bot/            # обработчики команд и сообщений Telegram
├── Services/        # бизнес-логика (парсер выражений, конвертер валют)
├── Data/            # доступ к SQLite
└── Models/          # модели данных (история вычислений)
```
